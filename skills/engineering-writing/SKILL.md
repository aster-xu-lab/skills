# 工程文档写作

先判断要写的是哪类文档，再选骨架。不同文档的编辑规则不同：**规范性**文档不能因为代码不符就弱化；**描述性**文档要跟代码一致；**历史性**文档不能改写；**runbook** 每一步必须真实跑过；**参考性**文档要穷尽字段。

不要默认项目使用某种目录、模板或语言。先读同目录 1–2 篇现有文档，沿用其结构、术语与格式。

## 适用与不适用

适用：

- 设计文档、RFC、提案、迁移方案、需要论证的“要不要做”。
- ADR、决策日志、记录“为什么这样选”。
- 事故复盘、根因分析、near miss 复盘。
- runbook、操作手册、发布与排障步骤。
- 变更日志、发布说明、API/事件/配置等契约文档。

不适用：

- 文档漂移修复、冗余精简、权威边界治理（走 `doc-governance`）。
- 已装 `documentation-and-adrs` 覆盖的通用 ADR 与文档漂移检查；本 Skill 补充中文工程文档骨架，不重复其规则。
- 博客、公众号等对外内容（走 `hexo-blog-post`）。
- 营销文案、UI 文案、纯翻译。

## 硬规则

1. **结论先行**：摘要第一段给出结论或建议，不从背景和方法讲起。（来源：技术写作的结论先行原则）
2. **事实、推断、提议分离**：已验证事实、合理推断、待决提议分别标注；不把提议写成已实现。（来源：本库诚实边界）
3. **每条主张可追溯**：数字、行为、引用要有来源；没有来源标 `[待补来源]`，不编造。（来源：本库证据要求）
4. **成本与收益并列**：只写收益像推销；代价、风险、不做什么同样要写。（来源：技术写作的成本并列原则）
5. **同一事实只写一处**：其他文档用链接，不复制正文。（来源：`doc-governance` 的事实唯一原则）
6. **历史文档不改写**：已评审的 ADR、复盘、变更日志只追加带日期的修订，不回改原文。（来源：历史完整性）
7. **行动项有归属**：每项写负责人/角色、验收方式；没有归属的“后续跟进”不算行动项。（来源：复盘与 runbook 的可执行要求）
8. **项目约定优先**：目录、编号、模板、语言以项目现有约定为准；没有约定时才用本 Skill 默认骨架。（来源：模板类 Skill 的先探测原则）

## 工作流

### 步骤 0：判定文档类型

先写一行工作笔记（不放进成稿）：

`类型：规范性/描述性/历史性/runbook/参考性 | 读者：谁 | 目的：读者要完成什么 | 非目标：本文不覆盖什么`

类型决定编辑规则；读者决定详略；目的决定结构。信息不足且会改变读者、范围或结论时先问，不编造。

### 步骤 1：读现有文档

1. 同目录最多读 2 篇同类文档，沿用结构、术语与格式。
2. 检查是否有索引 README；有则把新文档加入索引。
3. 检查同一主题是否已有权威文件；优先扩展已有文件，不新建竞争文档。

### 步骤 2：选骨架并写作

| 文档 | 读取 |
| --- | --- |
| 设计文档、RFC、提案、迁移方案 | `references/design-doc-and-rfc.md` |
| ADR、决策日志 | `references/adr-and-decision-log.md` |
| 事故复盘、runbook | `references/postmortem-and-runbook.md` |
| 变更日志、契约文档 | `references/changelog-and-contracts.md` |

骨架是默认值，不是强制模板；项目已有格式时优先项目格式。

### 步骤 3：自检

- 结论是否在第一段。
- 每个数字是否有来源；没有来源的已标注。
- 收益与代价是否并列；是否写了“不做什么”。
- 未完成部分是否标 `[待补]`，而不是省略。
- 开放问题是否有归属。
- 历史文档是否只追加、未改写。

### 步骤 4：交付

输出：文档路径、类型与读者、关键结论、未决问题、未核对事项。区分“已核对”与“待补来源”。

## 与现有能力边界

| 场景 | 使用 |
| --- | --- |
| 文档漂移、冗余、权威边界、索引治理 | `doc-governance` |
| 通用 ADR 与“文档是否过期”的检查 | 已装 `documentation-and-adrs` |
| 对外博客文章 | `hexo-blog-post` |
| 从零写工程文档、复盘、runbook、契约 | 本 Skill |

## 不做什么

- 不为“看起来完整”编造事实、数字、引用或负责人。
- 不把设计文档写成营销文案或过度承诺。
- 不改写已评审的历史文档；修订走带日期的追加。
- 不复制其他文档正文；用链接与指针。
- 不替项目决定目录与模板；先探测再套用。
