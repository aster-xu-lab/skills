# AsterXu Lab 投稿入口

先使用用户指定的博客目录，或从当前工作区定位已有 Hexo 站点，并确认目标站点。无法定位时询问实际位置，不自行创建或克隆博客。

1. **读取站点约定**：先读博客根目录的 `AGENTS.md`，再按任务需要读取 README、scaffolds、近期文章和相关配置。文章格式、命名、文风、分类、配图、发布时间与部署目标以博客项目说明和当前事实为准，不在本 Skill 重复维护。
2. **整理并写作**：保留原项目上下文，从用户指定的材料中提炼场景、机制、取舍和验证边界，在博客中生成或修改文章。不要把内部凭据或未获授权的项目细节写入文章；需要配图时按站点约定和当前可用工具处理。
3. **验证并交付**：使用博客现有构建命令，检查目标文章的生成物与链接；按需提供本地预览，交付文章文件、图片和验证结果。未构建、未预览或未发布时明确说明。
4. **按授权留档与发布**：区分源码提交、推送、图床上传和公网部署，分别核对用户已有授权与实际目标。未获发布授权时先交付可审阅结果，不把写作请求视为发布授权。（来源：用户授权边界与本站源码、部署职责）

历史分类治理、批量日期调整、主题修改和依赖升级需有对应请求，不作为投稿的附带操作。

文章需要外部研究、主笔/审校交接或配图时读取 `references/research-and-visuals.md`。它提供证据表与第三方能力选择，不重复本站格式或发布时间规则。已有工具优先；读取第三方入口不代表已安装、已生成或获准上传。
