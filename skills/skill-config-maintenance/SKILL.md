# Skill 外置配置审计与清理

用户需求：

$ARGUMENTS

本 Skill 只在用户显式调用时使用，不自动扫描或删除配置。

## 适用与不适用

适用：

- 公开分发的 Skill 在 `aster-xu-lab` 配置目录留下文件，需要盘点或清理。
- 需要区分：已安装 Skill 的配置、卸载后的孤立配置、未登记文件、损坏 JSON、权限异常、软链。
- 用户明确要求删除某个配置文件，并希望先备份。

不适用：

- 清理 Skill 管理工具的数据库、安装副本、宿主缓存或项目目录。
- 卸载 Skill、修改 Skill 内容或迁移业务配置。
- 自动批量删除目录，或处理 `aster-xu-lab` 之外的文件。

## 硬规则

1. **默认只读**：审计阶段不删除、不移动、不改写任何文件。
2. **删除三条件**：用户显式指定文件名、先归档、再用 `--yes` 确认。缺一项就停止。
3. **已安装 Skill 的配置不直接删**：脚本拒绝；只有用户再次确认并显式加 `--force` 才允许。
4. **软链不自动处理**：可能是 dotfiles 管理；报告后由用户自行决定，脚本拒绝自动删除。
5. **只扫描配置根目录的顶层 `*.json`**：不递归、不扫描其他目录、不读 Skill 管理工具的数据库。
6. **报告不打印配置值**：不输出站点路径、仓库路径、token 或提交内容；只报告文件名、状态、权限与原因。
7. **未登记文件只报告**：不因文件名陌生就删除；用户显式选择后才处理。
8. **删除后复跑审计**：确认剩余文件状态，归档路径写入清理记录。

## 流程

### 1. 定位

- macOS / Linux：`${XDG_CONFIG_HOME:-$HOME/.config}/aster-xu-lab`
- Windows：`%APPDATA%\aster-xu-lab`

目录不存在时直接报告“没有配置”，不创建目录。注册表在 `references/config-registry.json`。

### 2. 审计

运行：

```bash
python3 scripts/audit-configs.py --json
```

默认不检查安装目录；需要判断孤立残留时，把所用管理工具的安装目录传给 `--installed-root`。需要显式指定路径时：

```bash
python3 scripts/audit-configs.py --root <配置目录> --installed-root <已安装 Skill 目录> --json
```

把脚本状态映射为报告标签：

| 脚本状态 | 报告标签 | 处理 |
| --- | --- | --- |
| `ok` | 已登记且已安装 | 默认保留 |
| `orphan` | 孤立候选 | 可能是卸载残留；用户确认后可清理 |
| `unknown` | 未登记 | 只报告，不自动删除 |
| `invalid` | JSON 损坏 | 报告；用户决定备份后删除或修复 |
| `schema-mismatch` | schema 不匹配 | 报告；先确认版本迁移 |
| `symlink` | 软链 | 报告；不自动删除 |

权限不是 `0600` 时单独提示，不改变文件状态。

### 3. 报告

按文件输出：文件名、状态、权限、原因。汇总总数、孤立数、未登记数、损坏数与权限告警。明确区分“未发现问题”和“没有检查”。

### 4. 清理（仅在用户明确要求时）

1. 让用户逐项选择要删除的文件；不默认全选。
2. 确认目标文件不在已安装 Skill 的有效配置中；如果是，先说明影响并要求再次确认。
3. 先归档，再删除：

```bash
python3 scripts/audit-configs.py \
  --archive-dir <归档目录> \
  --delete --file <文件名> --yes
```

   归档目录使用独立目录；同名文件已存在时脚本拒绝移动，不会覆盖旧备份。
4. 已安装 Skill 的配置需要额外加 `--force`，并在命令前再次向用户确认。
5. 软链配置不自动删除；提示用户用 dotfiles 管理方式处理。
6. 删除后复跑审计，输出清理记录与剩余状态。

## 输出格式

```markdown
## 配置审计

- 配置目录：<路径>
- 注册表：<路径>
- 安装目录：<路径或「未检查」>
- 扫描文件：<N>

| 文件 | 状态 | 权限 | 说明 |
| --- | --- | --- | --- |
| <name>.json | 已登记且已安装 / 孤立候选 / 未登记 / JSON 损坏 / schema 不匹配 / 软链 | 600 / 其他 | <原因> |

## 清理记录

| 文件 | 原状态 | 归档位置 |
| --- | --- | --- |
| <name>.json | <状态> | <归档路径> |

## 未处理

<未登记、软链、schema 不匹配或用户未选择的文件；没有则写「无」。>
```

## 配置注册表

`references/config-registry.json` 是公开分发 Skill 的配置清单，字段：

- `file`：配置文件名。
- `schema_version`：期望版本。
- `description`：存什么。
- `reset`：删除后的影响与重新配置方式。

新增公开 Skill 写外置配置时，同步登记；未登记文件会被报告为“未登记”，不会被自动处理。

## 不做什么

- 不执行 `rm -rf` 或清空目录。
- 不自动清理、不批量删除、不默认全选。
- 不处理 Skill 管理工具的数据库、安装副本、宿主缓存、项目文件或 dotfiles 同步逻辑。
- 不把静态审计写成“配置已安全”的保证；删除前仍需用户确认。

## 与公开分发的关系

本 Skill 随公开分发提供，供使用已发布 Skill 的用户审计配置。它只读取本机 `aster-xu-lab` 配置目录和注册表，不依赖私有资产库、业务项目或远端服务。
